# 这个目录放什么

「B站「稍后再看」优化」项目里的 **SQL 查询截图** 与 **Figma 原型图** 需要你手动导出后放进本目录。

原因：这些图片存在飞书文档里，飞书对附件的下载接口要求登录态，脚本抓不到；截图只能由你在浏览器里导出。

## 最省事的做法

1. 用浏览器打开源文档，对着图片右键「图片另存为」，按上表命名。
2. PNG/JPG 直接改名成 `.webp` 后缀**不行**，需要真的转格式（参见根目录 `README.md` 里的转换命令）。
   如果你不想转格式，就把 HTML 里对应 `<img src="...webp">` 的扩展名改成 `.png`（共 10 处，在
   `projects/bilibili-slate.html` 里）。
