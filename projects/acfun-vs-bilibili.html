AcFun 与 Bilibili 竞品分析：定位差异与体验断层

两家都从 ACG 弹幕社区起步，产品形态相似、用户重叠度也高，十年后 B站 月活过了 3 亿， A站 还在千万级徘徊。把原因归给「内斗」太省事了，我更倾向于认为这是一次定位失焦和体验断层的叠加。

A站的问题不是某一个功能做错了。定位、体验、商业化这三件事互相咬合， 每一次「省一点钱」的选择在当时都说得通，叠加起来就成了一条完整的下行循环： 收入不够，技术投入就少，体验变差，用户流失，收入更少。

01 分析背景

为什么选这两个

AcFun 和 Bilibili 起点几乎一样：都是 ACG 文化起家的弹幕视频社区， 产品形态高度相似，用户群体重叠。但过去十年，两者走向了完全不同的方向。 B站 从「二次元小站」长成了月活超 3 亿的 Z 世代社区，A站 则从行业开创者慢慢滑到了边缘。

站在产品经理的角度看，我认为 A站 的掉队不能简单归咎于内部管理问题， 更值得拆的是一次典型的定位失焦加体验断层。所以这份分析从产品迭代和体验设计两个层面切入， 对比两家的战略选择和执行差异。

想回答三个问题

  1. 两家在产品定位和路径上到底差在哪，为什么会这样；
  2. A站 在用户体验上出现过哪几次关键断层；
  3. B站 做对了什么，A站 又做错了什么。

02 四维对比

维度AcFunBilibili
产品定位 硬核二次元垂直社区，强调圈层纯粹性，对新用户和泛二次元用户持保守甚至排斥的态度。社区氛围的纯度保住了，增长天花板也锁死了 Z 世代全场景文化社区，主动破圈，从 ACG 扩展到知识、生活、科技、汽车、财经等领域
核心用户 资深日漫宅和怀旧党，对氛围纯粹性的要求很高。这批人粘性高，但群体规模有限，而且随着年龄增长，内容消费的活跃度会自然下降 Z 世代，包括学生和职场新人，好奇心强，社区包容度也更高。用户结构持续保持年轻，生命周期价值更高
内容供给 长期依赖头部 UP 主和搬运工，创作者生态比较薄。UP 主没有系统的激励和成长路径，基本靠热情在更新。平台没有建立起内容的造血能力，头部创作者一走，供给就断 有 UP 主激励计划、创作学院、数据诊断工具和商业变现通道，形成了一个正循环。创作者能看到自己的成长路径，也能拿到实际回报
商业化 路径窄，主要靠直播打赏和少量广告，收入规模有限。收入不够，版权采购和技术投入就受限，形成负向循环 游戏、广告、会员、电商四条腿走路，收入结构多元。现金流支撑了版权采购、技术基建和创作者激励，形成正向循环

我没有按功能清单来对比，比如谁有弹幕、谁有投币，因为功能是可以抄的，抄不来的东西才是原因。 上面这四个维度是互相咬合的：定位决定用户结构，用户结构决定创作者的天花板， 创作者决定内容供给，内容供给决定商业化空间，而商业化的收入又反过来决定能不能继续投入体验。 两条曲线就是从这里分岔的。

03 三次体验断层

回头看 A站 的用户体验，有三次关键的断层直接导致了用户流失。它们发生在不同阶段， 但指向的是同一个问题。

第一次：注册门槛，错过移动互联网红利

2013 到 2014 年是移动互联网用户增长最猛的窗口期。B站 在这段时间大幅降低答题难度、 支持手机号注册，用户量井喷。A站 保留了高难度注册机制，直到 2018 年才全面开放注册。

后果是，在增长最关键的几年里，A站 把大量泛二次元用户挡在了门外。 同期 B站 MAU 已经超过 7000 万，而 A站 的用户规模被锁在核心二次元人群里。

第二次：观看体验崩溃

2015 到 2018 年之间，A站 频繁出现视频加载失败、清晰度锁死 360P、弹幕不同步这些问题。 更严重的是，因为没钱买带宽，A站 一度限制同时在线人数，用户晚上 8 点黄金时段打不开视频。

对视频社区来说，「看不了」比「没内容」更让人绝望。用户连续几次打不开视频，流失就是必然的。 而流失的往往是社区里最活跃、最有影响力的那批人。

第三次：创作者工具被拉开代差

B站 很早就做了投稿必读、创作指数、数据诊断这些工具，让 UP 主知道自己视频的表现、 受众是谁、该往哪个方向优化。A站 的 UP 主后台数据维度单一，连完播率这个核心指标都缺， 创作者没法有效优化内容。

工具上的差距最后体现在内容质量上。当 B站 UP 主开始稳定获得收入、有清晰成长路径的时候， A站 的头部 UP 主还在为播放量破十万庆祝。创作者一流失，平台就失去了内容生产的引擎。

断层发生阶段本质代价
注册门槛增长窗口期用门槛维护纯粹性，主动拒绝新用户用户天花板被锁死
观看体验规模扩张期为了省成本牺牲基础可用性核心用户大量流失
创作者工具生态建设期把创作者当内容来源，而不是合作伙伴失去内容生产引擎

04 反思

A站 错在哪

该做增长的时候选择了固守。在用户增长最猛的那几年，A站 用注册门槛维持社区纯粹性， 主动把新用户拒之门外。互联网产品的增长曲线一旦被拉开，追赶几乎不可能，因为网络效应决定了强者恒强。

该投基建的时候选择了省钱。在需要扩容带宽、优化播放器的阶段压缩成本， 结果用户连最基础的需求都满足不了。对视频社区来说，基础体验是那个 1，功能是后面的 0， 没有 1，再多 0 也没意义。

该建商业闭环的时候依赖单一收入。B站 用游戏、广告、会员、电商搭起多元营收体系时， A站 还主要靠直播打赏和少量广告。收入不足导致技术投入不足，技术投入不足导致体验恶化， 体验恶化导致用户流失，用户流失又让收入进一步萎缩，这条循环一旦转起来就很难停下来。

B站 做对了什么

B站 一直在做正确的选择题：判断对了移动端趋势，主动降低门槛吸纳新用户； 判断对了创作者生态的价值，持续投入激励和工具；判断对了商业化的必要性，搭起多元收入； 判断对了技术基建的重要性，持续优化播放体验和推荐算法。

05 总结

三个结论

定位的分野决定命运

起点相似，但定位不同导致结局不同。B站 主动破圈打开增长空间，A站 固守原有圈层，用户天花板被锁死。

三次断层是同一个原因

注册门槛、观看体验、创作者工具，发生在不同阶段，但共同指向一件事：在关键窗口期做了错误的产品决策。

功能优劣是综合结果

一个功能做得好不好，不只看「做没做」，而是产品策略、技术能力和用户洞察的综合体现。

我从中留下的判断清单

做完这份分析，我给自己留了三个问题，之后做功能设计前都会先过一遍：

问题AcFun 的答案B站 的答案
产品的核心价值还稳定吗 核心价值在泛二次元扩张中逐渐模糊 始终锚定社区文化和内容生态的根基
用户的基本体验守住了吗 技术欠账和运维失序，体验持续滑坡 稳定的播放体验和精准推荐，持续积累用户信任
商业能不能持续支撑体验优化 停留在对既有流量的粗放消耗上 游戏、广告、会员、电商多元协同，反哺技术投入

这三个问题的答案，基本决定了一个产品会进入正向循环还是负向循环。

这套清单我后来在做VOD 应用配置的时候真的用上了。 当时想过要不要把应用市场做成独立首页入口，用第一问一过就否掉了： 那样会削弱「设置域」这个定位，而换来的曝光收益并不足以补偿用户心智上的混乱。

下一步我想把这份分析从「事后归因」推进到「事前预判」： 挑两三个同一赛道的产品对，用这套清单做一次前瞻判断并记下来，半年后回来验证命中率。
