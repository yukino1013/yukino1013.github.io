起点相似，结局相反：
AcFun 做错了什么

两家同样从 ACG 弹幕社区起步的公司，十年后 B站 月活破 3 亿，A站 停在千万级。 把原因归给"内斗"太省事了——我认为这是一次典型的产品定位失焦与用户体验断层。

一句话结论

A站 的掉队不是某一个功能的失败，而是产品定位、用户体验、商业能力三者系统性脱节的结果。 每一次"省钱"的选择在当时都合理，但叠加起来构成了一条完整的负向循环： 收入不足 → 技术投入不足 → 体验恶化 → 用户流失 → 收入进一步萎缩。

01 分析背景

1.1 分析对象选择

AcFun 与 Bilibili 同为中国 ACG 文化起家的弹幕视频社区，产品形态高度相似、用户群体重叠度高。 然而过去十年间，两者走向了截然不同的发展路径：B站 从"二次元小站"成长为月活超 3 亿的 Z 世代文化社区， AcFun 则从行业开创者逐步滑向边缘。

站在产品经理视角，我认为 AcFun 的掉队不能简单归咎于"内斗"，而是一次典型的产品定位失焦与用户体验断层。 本报告从产品迭代和体验设计两个层面切入，对比两平台的战略选择与执行差异，分析为何起点相似的公司走向不同的结局。

1.2 分析目标

本次分析聚焦三个核心问题：

  1. AcFun 与 B站在产品定位和战略路径上的差异及其成因；
  2. AcFun 在用户体验层面的三次关键"断层"；
  3. B站做对了什么，而 A站做错了什么。

02 四维策略对比

维度AcFunBilibili
产品定位 硬核二次元垂直社区，强调圈层纯粹性，对新用户和泛二次元用户持保守甚至排斥态度。保持了氛围"纯度"，但也锁死了增长天花板 Z 世代全场景文化社区，主动破圈，从 ACG 拓展至知识、生活、科技、汽车、财经等多元内容领域

这一节的方法论

我刻意不按"功能清单"对比（谁有弹幕、谁有投币），因为功能可以抄，抄不来的东西才是原因。 上面四个维度是互相咬合的：定位决定用户结构，用户结构决定创作者的天花板，创作者决定内容供给， 内容供给决定商业化空间，商业化收入再反过来决定能不能继续投入体验——这正是两条曲线分岔的地方。

03 三次致命体验断层

如果我们细看 AcFun 的用户体验，可以发现有三次关键的"体验断层"直接导致了用户流失。它们发生在不同的发展阶段，却共同指向同一个问题。

3.1 注册门槛高，错失移动互联网红利

2013 至 2014 年是移动互联网用户增长最迅猛的窗口期。B站在这一时期大幅降低答题难度、支持手机号注册， 用户量实现井喷式增长。而 AcFun 长期保留高难度注册机制，直到 2018 年才全面开放注册。

直接后果是：在用户增长最关键的几年里，AcFun 把大量泛二次元用户拒之门外。同期 B站 MAU 已超过 7000 万， 而 AcFun 的用户规模被锁定在核心二次元人群，错失了移动互联网时代最大的一波红利。

3.2 灾难级别的观看体验

2015 至 2018 年间，AcFun 频繁出现视频加载失败、清晰度锁死 360P、弹幕不同步等问题。 更致命的是，因为没钱买带宽，AcFun 甚至限制同时在线人数——用户晚上 8 点黄金时段打不开视频。

这是产品经理眼中"服务不可用"级别的灾难。对视频社区而言，"看不了"比"没内容"更让用户绝望。 当用户连续几次打不开视频时，流失是必然结果。而流失的核心用户，往往是社区中最活跃、最有影响力的那批人。

3.3 创作者工具遭到降维打击

B站很早就推出"投稿必读""创作指数""数据诊断"等辅助工具，让 UP 主清楚知道自己的视频表现、受众画像和优化方向。 而 AcFun 的 UP 主后台数据维度单一，连"完播率"这一核心指标都缺失，创作者无法有效优化内容。

创作者工具的差距，最终体现为内容质量的全面落后。当 B站 UP 主开始月入过万、获得系统性成长路径时， AcFun 头部 UP 主还在为"播放量破十万"庆祝。创作者的流失，意味着平台失去了内容生产的引擎。

断层发生阶段本质代价
注册门槛增长窗口期用门槛维护"纯粹性"，主动拒绝新用户锁死用户天花板
观看体验规模扩张期为省成本牺牲基础可用性核心用户大量流失
创作者工具生态建设期把创作者当成内容来源而非合作伙伴失去内容生产引擎

04 产品经理视角的反思

4.1 AcFun 做错了什么

① 该做增长时，选择了固守

在用户增长最迅猛的窗口期，AcFun 选择用注册门槛维护社区"纯粹性"，主动拒绝了新用户。 而互联网产品的增长曲线一旦被拉开，追赶几乎不可能——网络效应决定了"强者恒强"。

② 该投基建时，选择了省钱

在需要扩容带宽、优化播放器的关键阶段选择节省成本。 对视频社区而言，基础体验是 1，功能是后面的 0——没有 1，再多的 0 也无意义。

③ 该建商业闭环时，选择了依赖单一收入

B站通过游戏、广告、会员、电商构建多元营收体系时，A站仍依赖直播打赏和少量广告。 收入不足 → 技术投入不足 → 体验恶化 → 用户流失 → 收入进一步萎缩，负向循环一旦形成，扭转难度极大。

B站做对了什么

反观 B站，始终在做正确的选择题：

  • 移动端优先 — 判断对趋势，主动降低门槛吸纳新用户
  • 创作者优先 — 判断对生态价值，持续投入激励和工具
  • 数据驱动优先 — 判断对方向，用工具帮创作者优化内容
  • 技术基建优先 — 判断对质量的重要性，持续优化播放体验与推荐算法
最扎心的一条

面对商业化的浪潮，AcFun 的应对更像是一场明知结局却仍要挣扎的困兽之斗—— 每一次试图追赶的动作，都在慢半拍的节奏中被市场无情甩开。 产品决策的代价不是当下支付的，而是在两三年后一次性结算。

05 总结

5.1 三个核心发现

① 定位的分野决定命运

A站 与 B站 起点相似，但产品定位的分野导致了两者截然不同的命运。B站主动破圈打开增长空间，A站被动固守导致用户天花板被锁死。

② 三次断层同一根因

注册门槛过高、观看体验崩溃、创作者工具缺失——发生在不同发展阶段，但共同指向：产品决策在关键窗口期做出了错误选择。

③ 优劣是综合体现

产品功能的优劣不仅仅是"做或不做"的问题，而是产品策略、技术能力和用户洞察的综合体现。A站掉队是三者系统性脱节的结果。

5.2 我从中获得的判断框架

通过本次竞品分析，我认识到对于产品经理而言，做任何功能设计之前都需要先回答三个问题：

问题AcFun 的答案B站 的答案
产品的核心价值是否稳定？ 核心价值在泛二次元扩张中逐渐模糊 始终锚定社区文化与内容生态的根基不动摇
用户的基本体验是否得到保障？ 在技术欠账和运维失序中持续滑坡 以稳定的播放体验和精准的推荐机制持续积累用户信任
商业能否持续支撑体验优化？ 停留在对既有流量的粗放消耗上 通过游戏、广告、会员、电商的多元协同，构建反哺技术投入的良性资金链

这三个问题的答案，决定了一个产品是进入正向循环还是负向循环。 三个问题一一对照，胜负早已写在了两条曲线的走向里。

这个方法我用在哪里

这套框架后来成了我做任何功能设计前的自检清单。在 VOD 应用配置 项目里， 我就用它砍掉了一个"看起来该做"的设计：把应用市场做成独立首页入口——因为那会削弱"设置域"这一核心价值的稳定性， 而它带来的曝光收益并不能补偿用户心智上的混乱。

下一步

把这份分析从"事后归因"推进到"事前预判"：选取 2–3 个当前处于同一赛道的产品对， 用这套框架做一次前瞻性判断并记录预测，半年后回头验证框架的命中率。
